# Repository Investigation & Code Recon Capability Profile
*Focus: Dependency topology mapping, architectural survey, pattern discovery, convention extraction*

- Survey the codebase systematically: identify package managers, build scripts, entry points, configuration registries, and test suites.
- Map the high-level data flow and call hierarchy before examining specific module implementations.
- Discover and respect existing conventions for naming, directory structure, error handling, and testing.
- Differentiate between active production code, legacy migration artifacts, and third-party vendor dependencies.
- Produce structured summaries with file links and line ranges to ground subsequent development tasks.
